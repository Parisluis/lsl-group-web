# L$L Group — Web

Primer prototipo del sitio de L$L Group. HTML, CSS y JavaScript sin compilación.

## Vista previa
Abrir index.html en un navegador. Las tipografías requieren conexión a Google Fonts.

## Contenido
- index.html: estructura y contenido.
- style.css: diseño adaptable y animaciones.
- app.js: navegación, fichas, montaje conceptual y consulta descargable.
- assets/editorial.png: fotografías conceptuales generadas para el prototipo.

## Pendientes
Reemplazar imágenes y marcas provisionales por materiales originales, incorporar el showreel real y conectar el formulario al destino de contacto definitivo. Actualmente las consultas se descargan; no se envían a un servidor.

El prototipo incluye control para pausar el movimiento y respeta la preferencia de movimiento reducido.
