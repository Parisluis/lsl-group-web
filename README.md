# L$L Group — Web

Primer prototipo del sitio de L$L Group, con HTML, CSS y JavaScript sin compilación.

Abrir index.html en un navegador. Las tipografías requieren conexión a Google Fonts.

Incluye diseño adaptable, animaciones con control de pausa, servicios y proyectos interactivos y consulta descargable. Las fotografías son conceptuales y se reemplazarán por materiales originales. El formulario no envía datos a un servidor.
